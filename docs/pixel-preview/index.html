Fieldbook in Pixels

Real Portugal geometry from the Protomaps tiles, rasterised to a 1.5 m grid and drawn with Kenney's CC0 Tiny Town tiles. Drag to pan, pinch or use the buttons to zoom.

What you are looking at

  • Every road, building and courtyard is real. Each area is a 240 × 160 cell window cut from the zoom‑15 Protomaps build, so the plan matches what a normal map shows at the same spot.
  • Buildings show a south face. Roof over the footprint, two wall rows with a door and windows on the southern edge, and a one‑cell roof overhang above the northern edge. That is the Stardew trick; no pitch, no 3D.
  • Trees are data too. The trees in Lagos' squares are mapped tree points. Rural tree cover would come from forest and scrub polygons.
  • The walking character is a placeholder drawn by hand at the window centre.

Tile sources

Grass, flowers, dirt paths, roofs, walls, doors, trees: Kenney Tiny Town (CC0) Water, sand, wetland, rock, cobbled road: generated stand‑ins, the pack has none Edges and outlines: drawn procedurally per cell, not from a tileset

Findings that change the plan

  • The app's tiles are the wrong zoom for this. In the same Lagos window the current zoom‑13 archives contain 1 building, zoom 14 has 3, zoom 15 has 247. A Stardew view needs zoom‑15 data, which means a bigger download or extracting it only around chosen zones.
  • The configured build has expired. The 7 September Protomaps file returns 404; the preview used the 15 September build. The map build config needs the date bumped before any rebuild.
  • Diagonal streets staircase. Stardew maps are authored axis‑aligned; real Lagos is not. At 1.5 m cells every diagonal road and wall shows steps. Options are larger cells, diagonal transition tiles in the tileset, or accepting it.
  • Old‑town blocks arrive merged. OSM maps whole terraces as one polygon, so a block gets one door. Splitting fronts every few cells is a rendering rule, not a data fix.
  • Rural areas are quiet. The start point is wetland with two footpaths and nothing else. Fields, scrub and reeds will need decorative sprites sown by landuse type to feel alive.
